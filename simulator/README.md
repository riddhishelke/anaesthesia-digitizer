# Medical Monitor Simulator

This simulator mimics a real anaesthesia monitor display for hackathon demo and testing purposes. It features two different visual "brands" of monitors to prove that the reading system works across different screen designs.

## Folder Structure

- `brand-a/index.html` - Anaesthesia monitor simulator display for Brand A.
- `brand-b/index.html` - Anaesthesia monitor simulator display for Brand B.
